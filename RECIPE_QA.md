## Что подтверждено автоматически
- 94 уникальных названия, у всех присутствуют ингредиенты, время и инструкция.
- Для всех ингредиентов определена единица измерения и базовая расчётная норма.
- Таймлайн рассчитывается из оценочной длительности; фактические минуты не измерялись.
- Фото подбираются по внешнему поиску и не могут считаться подтверждённым изображением точного результата блюда.

## Что необходимо для выпуска проверенной коллекции
1. Кулинарный редактор проверяет рецептуру каждого блюда и сырой/готовый вес.
2. Проводится контрольная готовка с замерами подготовки и нагрева.
3. Создаётся либо подбирается фотография именно приготовленного по рецепту блюда с проверенными правами.
4. Для блюд с курицей проверяется температура готовности внутри продукта (74 °C), для яиц — безопасная готовность.
